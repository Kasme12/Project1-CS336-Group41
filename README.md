# Project-1-CS336 Group 41

Project Group 41: Ege Canli (eec74), Travis Feldman (tjf149), Samuel Sabala Polanco (ss2867), Esmeralda Bencosme (eb1024)

We must design and build a complete online flight‑reservation system using Java Swing, MySQL, and JDBC. 
This includes creating an ER diagram and relational database schema that model airlines, airports, aircrafts, flights, tickets, customers, and employees, along with all relationships and integrity constraints.
Then we must implement a Java application that lets customers search flights, make one‑way/round‑trip/flexible reservations, join waiting lists, view past and upcoming trips, and manage cancellations. 
Customer representatives must be able to create and edit reservations and manage flight‑related data, while admins must manage users and generate reports such as sales summaries, revenue breakdowns, and lists of active flights. The system must enforce access control so each user type only sees what they are allowed to see, and the Swing interface must be simple and functional. 
The final deliverables are the relational schema and the full Java program.
