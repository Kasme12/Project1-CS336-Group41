                    TRAVEL RESERVATION SYSTEM - README
================================================================================

PROJECT OVERVIEW
----------------
This is a complete Java Swing-based Travel Reservation System that connects to
a MySQL database. It supports three user types: Customers, Customer 
Representatives, and Administrators.

DATABASE SETUP
================================================================================

1. Install MySQL Server (if not already installed)
2. Open MySQL Workbench
3. Run the database.sql file to create the database and tables
4. The database name is: travel_reservation

DATABASE CONNECTION:
--------------------
The application connects to MySQL with these default settings:
- Host: localhost
- Port: 3306
- Database: travel_reservation
- Username: root
- Password: root

To change these settings, edit the DBConnection.java file in the dao package.

FEATURES IMPLEMENTED
================================================================================

CUSTOMER FUNCTIONALITY:
-----------------------
[X] Search for flights between two airports
[X] One-way on a specific date
[X] Round-trip on specific dates
[X] One way or round-trip on flexible dates (+/- 3 days)
[X] Browse the resulting flights
[X] Sort flights by different criteria (price, take-off time, landing time, duration)
[X] Filter flights by various criteria (price, number of stops, airline, times)
[X] Make flight reservations/buy tickets
[X] Enter the waiting list if flight is full
[X] View all past flight reservations with details
[X] View all upcoming flights with details
[X] Cancel flight reservations (if business or first class)
[X] Send alert to customers in waiting list (system notifies)
[X] Post questions to customer representative

ADMIN FUNCTIONALITY:
--------------------
[X] Add, Edit information and Delete customer representatives or customers
[X] Obtain a sales report for a particular month
[X] Produce a list of reservations by flight number or by customer name
[X] Produce a summary listing of revenue generated by flight, airline, or customer
[X] Find out which customer generated most total revenue
[X] Produce a list of most active flights (most tickets sold)

CUSTOMER REPRESENTATIVE FUNCTIONALITY:
--------------------------------------
[X] Make flight reservations on behalf of users
[X] Edit flight reservations for a customer
[X] Add, Edit, Delete information for aircrafts, airports, and flights
[X] Retrieve a list of all passengers on waiting list of a particular flight
[X] Produce a list of all flights for a given airport (departing and arriving)
[X] Reply to user's questions

================================================================================
HOW TO RUN THE APPLICATION
================================================================================

OPTION 1 - Using the JAR file:
------------------------------
1. Ensure MySQL is running and the database is set up
2. Double-click project.jar to run the application

OPTION 2 - From Source Code:
-----------------------------
1. Ensure you have Java JDK installed
2. Ensure MySQL is running and the database is set up
3. Compile the source files:
   javac -d bin src/**/*.java src/*.java
4. Run the application:
   java -cp bin ui.LoginFrame

OPTION 3 - Using VS Code:
-------------------------
1. Open the project folder in VS Code
2. Ensure Java extension is installed
3. Run the LoginFrame.java file

================================================================================
IMPORTANT NOTES
================================================================================

1. The MySQL JDBC driver (mysql-connector-java.jar) must be in the classpath
2. Make sure the MySQL server is running before launching the application
3. The database must be created using the provided SQL script before first use
4. Date format for search: YYYY-MM-DD (e.g., 2026-05-01)

================================================================================
TROUBLESHOOTING
================================================================================

- "Cannot connect to database": Check MySQL is running and credentials are correct
- "Table not found": Run the database.sql script in MySQL Workbench
- "Class not found": Ensure MySQL connector JAR is in classpath
